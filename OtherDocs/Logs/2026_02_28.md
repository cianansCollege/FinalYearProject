# 4. Evaluation Pipeline Improvements

## 4.1 Initial Issue

Original cross-validation used `GroupKFold`, resulting in:

* Highly imbalanced folds
* Extreme class distribution variance
* Unstable performance metrics

## 4.2 Upgrade to StratifiedGroupKFold

Replaced:

```python
GroupKFold
```

with:

```python
StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42)
```

Ensures:

* Speaker-safe splits
* More balanced class distribution per fold
* More reliable evaluation

# 6. Feature Experiment: Distributional MFCC Stats

Upgraded MFCC feature extraction from:

* Mean + Std

to:

* Mean
* Std
* Median
* IQR (75th–25th percentile)

Feature dimensionality increased from 52 → 104.

### Result

No significant improvement:

* Accuracy ~40%
* Confusion pattern unchanged

### Interpretation

Distributional MFCC statistics alone do not capture sufficient accent variation between southern provinces.
