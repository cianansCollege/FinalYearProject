**Daily Log – Results Visualisation and Evaluation**

**Date**

21 March 2026

---

**Work completed today**

Today I focused on transforming my experimental results into clear, structured visualisations for the Final Year Project and improving the overall quality of the evaluation.

The first task involved recovering from a data issue where my summary CSV file was accidentally overwritten in Excel. Since the project stores individual model outputs in structured folders, I was able to rebuild the full results table using the `summary.json` files for each model. This reinforced the importance of keeping a reliable source-of-truth dataset separate from any Excel-based analysis.

I then began constructing charts in Excel to visualise the results. I created per-task model comparison charts, ensuring that each chart only contained a single classification task. This required fixing several issues such as incorrect axis labelling, Excel defaulting to numeric x-axes, and charts dynamically changing when filters were applied. I resolved this by copying filtered data into static tables for each chart.

Considerable time was spent improving the presentation of these charts. I standardised model names (e.g. “Logistic Regression”, “SVM (RBF Kernel)”), simplified task names, sorted models by performance, and ensured consistent formatting such as horizontal bars for model comparisons and vertical bars for summary charts. I also introduced a random baseline into each chart and ensured it was visually distinct.

I then developed higher-level summary charts. First, I created a chart showing the best-performing model for each task, followed by a task difficulty chart based on average performance across models. These helped reveal that binary classification tasks perform significantly better than multi-class province classification.

A key improvement today was introducing relative improvement over baseline as a metric. This was calculated as (score − baseline) / baseline and allowed fair comparison across tasks with different numbers of classes. Using this metric, I created a model comparison chart showing average relative improvement across all tasks.

This final chart showed that Logistic Regression (particularly the weighted version) and Linear SVM performed best overall, while k-NN models consistently performed worst. However, the overall spread between models was moderate, suggesting that model choice is less important than task difficulty and dataset characteristics.
