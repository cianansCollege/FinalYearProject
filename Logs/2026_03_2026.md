Daily Log – Prototype3 UI and Next-Step Planning

Date

11 March 2026

Work completed today

Today I continued refining the Prototype3 accent mapping system and improved the end-to-end usability of the project. The main focus was on getting the frontend, backend, and prediction pipeline working together more reliably.

A major part of the work involved integrating the frontend with the FastAPI backend so that the homepage could be served correctly rather than only the API documentation page. This required updating the backend routing and static file setup so the website could be accessed directly from the root URL.

I also fixed several frontend integration issues. Static assets such as CSS and JavaScript were not initially loading correctly because of incorrect file paths, and browser caching caused older versions of files to continue loading even after changes were made. After correcting the paths and forcing hard refreshes, the frontend updates began appearing properly.

The recording and upload workflow was then improved. Audio file upload was added to the interface, and the prediction button logic was fixed so that users can now upload a file and then submit it for prediction. Browser audio recording was also updated to enforce a minimum recording length of 10 seconds, and a countdown indicator was added so the user can clearly see when the recording is long enough.

The map section was upgraded from placeholder province cards to a real Leaflet map using province GeoJSON boundaries. The prediction result now highlights the correct province visually, and a reset map view button was added so the user can return to the original Ireland view after panning or zooming.

Finally, I reviewed the current visual appearance of the interface. While the Bootstrap-based layout is functional and clear, it currently feels too generic and visually dull. I noted that although the project is not frontend-focused, the interface still needs to look more polished and intentional for the final submission and any live demonstration.

Key outcomes
	•	Frontend now loads correctly from the backend root route
	•	Static assets are being served properly
	•	Audio upload works
	•	Browser recording works with a 10-second minimum rule
	•	Prediction button behaviour is functioning correctly
	•	Real province-level map added with highlight support
	•	Reset map view feature added
	•	Current UI assessed for future improvement

Issues identified
	•	The interface looks too default-Bootstrap and lacks a distinctive visual identity
	•	The page layout does not fully use the available vertical screen space on larger landscape displays
	•	The current prediction panel is too empty and does not yet support prediction history
	•	More work is needed to support multiple models cleanly in the interface
	•	Mozilla Common Voice integration will require handling non-Irish accent outputs and corresponding geographic visualisation
