# 2. Analysis of Irish Accent Model Experiments

The automated experiment framework generated **67 model runs across multiple tasks**, including:

- Province classification (4-way)
- Dáil-only province classification
- Ulster vs Rest
- Leinster vs Rest
- Ulster–Leinster–Rest
- Dáil vs Northern Ireland dataset classification

## Key Findings

### Province Classification
Performance remained close to chance:

- Best balanced accuracy ≈ **0.39**

This indicates that **Irish provincial accents are difficult to distinguish using MFCC-based classical ML models**.

### Binary Regional Tasks
Simpler regional splits produced stronger results:

- Leinster vs Rest ≈ **0.61 balanced accuracy**
- Ulster vs Rest ≈ **0.74 balanced accuracy**

This suggests **Ulster speech patterns are more acoustically distinct**.

### Dataset Classification (Dáil vs NI)
This task performed very well:

- Balanced accuracy ≈ **0.78**

This indicates that **Northern Irish and Republic of Ireland speech differ strongly enough to be detected by ML models**.

These results provide a strong experimental foundation for the dissertation.

# 3. Preparation of International Accent Dataset

To validate the ML pipeline using a larger and more diverse dataset, work began on integrating the **Mozilla Common Voice English corpus**.

The dataset archive (~100GB) was inspected without full extraction to avoid disk space issues.

Archive structure:
cv-corpus-24.0-2025-12-05/en/
train.tsv
dev.tsv
test.tsv
validated.tsv
clips/

The **validated.tsv metadata file** contains over **1 million speech clips**.

---

# 4. Metadata Quality Investigation

Inspection of the `accents` column revealed:

- **354 unique accent labels**
- Many values were **self-typed and inconsistent**
- Examples included spelling variants and ambiguous categories.

Due to this, the raw accent labels could not be used directly for modelling.

---

# 5. Accent Label Normalisation

To address the inconsistent metadata, a manual mapping table was created: AcceptableGroups.csv

This file contains three columns:

| Column | Purpose |
|------|------|
| PreviousAccentClassification | Original Common Voice accent label |
| AccentGroup | Normalised regional group |
| SubGroup | Optional finer classification (e.g., NI vs ROI) |

Accents not listed in this table are **excluded from the dataset**.

---

# 6. Defined Accent Groups

Accent labels were consolidated into **five regional groups**:

- **UK**
- **Ireland**
- **North America**
- **Indian Subcontinent**
- **Oceania**

This grouping reduces metadata noise while retaining meaningful linguistic distinctions.

Additionally, the **Ireland group is subdivided** into:

- Northern Ireland
- Republic of Ireland

to allow for a secondary experiment comparing NI vs ROI speech patterns.

---

# 7. Metadata Filtering Script

A Python preprocessing script was implemented to:

1. Load the Common Voice `validated.tsv` metadata.
2. Load the accent mapping table.
3. Merge the datasets based on accent labels.
4. Remove rows without valid accent mappings.
5. Produce a **clean filtered metadata file** for downstream experiments.

The output metadata format mirrors the Irish dataset schema:
filepath
speaker
label
dataset
subgroup
raw_accent
clip_filename

This ensures the **existing training pipeline can be reused without modification**.
