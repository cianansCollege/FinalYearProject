11. Experiment 03 – Binary Ceiling Test (Ulster vs Rest)

Objective

To determine whether the dataset contains strong macro-accent signal, or whether the 4-class performance (~41%) reflects a fundamental data limitation.

Binary task:
	•	Ulster
	•	Rest (Connacht + Leinster + Munster)

Evaluation remained:
	•	MFCC + delta statistical features (104 dimensions)
	•	Logistic Regression (class_weight=“balanced”)
	•	StratifiedGroupKFold (speaker-safe)

⸻

Results
	•	Accuracy: 77%
	•	Macro F1: 0.74
	•	Ulster F1: 0.65
	•	Rest F1: 0.83

Interpretation
	•	Strong macro-regional separability exists.
	•	The dataset contains substantial accent signal.
	•	The issue in the 4-class task is likely fine-grained southern province overlap, not total absence of structure.

This disproved the hypothesis that the dataset was fundamentally insufficient.

⸻

12. Experiment 04 – 3-Class Restructuring

Ulster / Leinster / Rest

Objective

To test whether reducing label granularity improves performance relative to 4-class classification.

New label mapping:
	•	Ulster → Ulster
	•	Leinster → Leinster
	•	Connacht + Munster → Rest

⸻

Results
	•	Accuracy: 47%
	•	Macro F1: 0.48

Confusion remained high between:
	•	Rest ↔ Leinster

Ulster continued to perform strongest (F1 ≈ 0.63).

⸻

Interpretation
	•	Reducing from 4 to 3 classes improves accuracy modestly.
	•	However, southern regional overlap persists.
	•	Structural difficulty lies in separating Leinster from western/southern provinces.

13. Domain Confound Hypothesis Raised

A critical concern emerged:

Is Ulster performance driven by recording location differences (DAIL vs NI), rather than accent?

Given that:
	•	Most southern provinces are from DÁIL recordings
	•	Many Ulster recordings originate from NI Assembly

A confound between province and recording domain was plausible.

⸻

14. Experiment 05 – Recording Domain Classification (DAIL vs NI)

Objective

Test whether recording source (DAIL vs NI) is highly learnable, indicating strong domain shift.

Target:
	•	DAIL
	•	NI

Same:
	•	Features
	•	Model
	•	Speaker-safe CV

⸻

Results
	•	Accuracy: 82%
	•	Macro F1: 0.76

Confusion Matrix:

              Predicted
            DAIL     NI
Actual DAIL  1107    175
Actual NI     130    262


⸻

Interpretation
	•	Recording domain is strongly separable.
	•	There is substantial acoustic difference between DÁIL and NI recordings.
	•	Domain confounding is real and must be considered in province interpretation.
