1. Objective of Session

The objective of this session was to review the current state of the Final Year Project and clarify the direction for the remaining development and experimentation. The focus was on defining the final project framing and preparing the system for further machine learning testing.

⸻

2. Project Review

A review of the current system architecture was carried out. The project currently consists of:
	•	A frontend web interface for recording user speech
	•	A FastAPI backend for handling prediction requests
	•	A modular model registry allowing different ML models to be plugged into the system
	•	A machine learning pipeline for preprocessing audio and generating predictions

This architecture allows the system to support multiple models without requiring changes to the frontend.

⸻

3. Dataset Preparation

Work continued on preparing additional datasets for experimentation. The Mozilla Common Voice English dataset is being downloaded in order to test the machine learning pipeline on a larger and more diverse dataset.

This will help determine whether current model performance issues are caused by the dataset or the modelling approach.

⸻

4. System Framing

The project description and framing were reviewed to better reflect the current implementation. The project now focuses on:
	•	Building a complete machine learning pipeline
	•	Testing multiple accent classification models
	•	Integrating models into a web platform
	•	Visualising predictions using geospatial mapping
	•	Evaluating the limitations of accent classification

5. Next Steps

Planned work for the next sessions includes:
	•	Completing the Common Voice dataset download
	•	Training models on the new dataset
	•	Comparing model performance
	•	Continuing improvements to the modular ML system
