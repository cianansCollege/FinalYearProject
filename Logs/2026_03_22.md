Daily Log – Global Analysis, Charting, and Wav2Vec Experimentation

Date

22 March 2026

Work completed today

Today focused on completing the analysis phase of the project by finalising evaluation charts, refining the global dataset experiments, and introducing a new exploratory experiment using pretrained wav2vec embeddings.

The day began with constructing a series of evaluation charts in Excel based on the Irish and global experiment outputs. This included creating model comparison charts, task-level performance charts, and a normalised metric using relative improvement over baseline. This metric allowed fair comparison across tasks with different class counts and became a key part of the analysis. Care was taken to clean model and task naming conventions to ensure the charts were suitable for both the final report and poster.

A model-level chart was created showing average relative improvement over baseline across all tasks. This revealed that no classical model significantly outperformed others, supporting the conclusion that classifier choice was not the primary limiting factor. A second comparison chart between the Irish dataset and the Common Voice global dataset showed a clear performance gap, with Irish tasks achieving substantially higher improvements over baseline. This highlighted the importance of dataset quality and consistency, and demonstrated that global accent classification is significantly more difficult.

Following this, the global pipeline was extended and cleaned. Additional tasks were added, including Ireland vs North America, Ireland vs Oceania, and a four-way global classification. The dataset was refined to include a Northern Ireland category, improving label granularity and enabling more meaningful comparisons. The updated pipeline was run successfully and new results were generated for all tasks.

The final and most important step of the day was implementing a wav2vec-based feature extraction pipeline. A new experimental module was created to use a pretrained wav2vec2 model as a feature extractor, replacing MFCC features with learned speech embeddings. This was implemented in a separate pipeline to avoid disrupting the existing system. Two tasks were selected for evaluation: Ulster vs Rest (binary) and Province 4-way (multi-class). Logistic Regression and weighted Logistic Regression were used as classifiers to maintain consistency with earlier experiments.

The wav2vec experiments were successfully executed. For the Ulster vs Rest task, wav2vec achieved a balanced accuracy of approximately 0.76, representing a small improvement over the MFCC baseline. For the Province 4-way task, wav2vec achieved a balanced accuracy of approximately 0.46, compared to around 0.38 using MFCC features. This represents a substantial improvement and demonstrates that learned representations are more effective for complex multi-class accent classification tasks.

Key outcomes

• Demonstrated minimal performance differences between classical ML models

Issues identified
• Global dataset performance remains low despite increased task variety  
• ROI vs NI task initially failed due to label mismatch in dataset  
• Wav2vec pipeline is computationally expensive and slow on CPU  
• Limited feedback during embedding extraction made monitoring difficult  
• Dataset label inconsistencies required adjustment of task definitions
