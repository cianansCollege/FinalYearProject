6. Reusable ML Pipeline

A generic pipeline (pipeline_utils.py) was created based on the previous training script.

The pipeline performs:
	1.	Metadata loading
	2.	MFCC feature extraction
	3.	Feature summarisation (mean + standard deviation)
	4.	Speaker-safe cross-validation
	5.	Model training
	6.	Metric computation

Cross-validation uses:

StratifiedGroupKFold

with speaker ID as the grouping variable, ensuring that audio from the same speaker never appears in both training and test sets.

This prevents speaker leakage, a common issue in speech recognition experiments.

9. Observations During Execution

Several warnings appeared during logistic regression training:

ConvergenceWarning: lbfgs failed to converge

This indicates that the optimisation process reached the maximum iteration limit.

The likely cause is unscaled MFCC features, which can affect optimisation-based algorithms.

However, the experiments still completed successfully and produced valid evaluation metrics.
